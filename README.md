# Барельеф Бук — контакты

Одноэкранная мобильная страница-визитка для NFC-метки: фото на фоне, название и кнопки
(Instagram, Telegram-канал, личка в Telegram, два телефона).

Чистый HTML + CSS, без JS, без сборки и внешних зависимостей (шрифт системный).

## Структура

```
index.html   — страница
bg.jpg       — фоновое фото (1500×2000, ~180 КБ)
.nojekyll    — чтобы GitHub Pages отдавал файлы как есть
```

## Запуск

Открыть `index.html` в браузере или поднять локально:

```bash
python3 -m http.server 8000
```

## Выкладка на GitHub Pages

1. Залить репозиторий на GitHub.
2. Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`.
3. Адрес вида `https://<user>.github.io/<repo>/` записать в NFC-метку.

Для своего домена: в тех же настройках Pages указать Custom domain.

## Что где менять

| Что | Где |
|---|---|
| Контакты и ссылки | блок `<nav class="links">` в `index.html` |
| Название и описание | `<h1 class="title">` и `<p class="sub">` |
| Какую часть фото видно на узких экранах | `--bg-x` в начале CSS (0% — левый край, 100% — правый) |
| Стиль кнопок | класс `.btn` |

Фон лежит рядом как `bg.jpg`. Если заменить фото, лучше сжать до ~1500 px по высоте и до 200–300 КБ,
чтобы страница открывалась мгновенно при касании метки.
